四国遍路フィールドワーク ツール選択
Smart itinerary & research fieldwork manager
🔍for my own research use only

四国遍路フィールドワークを支える 2 つのツールです。スマート旅程プランナーは日程と札所の半自動スケジューリング、フィールドワーク管理ツールは研究設計・インタビュー・ノート管理など、修論全体の現場ワークを整理するための画面です。

📅
スマート旅程プランナー
四国八十八ヶ所の札所データをもとに、開始札所・終了札所と日程を設定すると、距離に応じて札所を各日に自動配分します。ドラッグ＆ドロップでアンカーを置くと、間の札所が半自動で調整されるので、多少抜けのある計画でも帳尻が合うように補完できます。
📚
フィールドワーク全体管理
修論の研究設計、インタビュー管理、フィールドノート、札所訪問記録などを一元的に管理するための画面です。Berger の社会的構築主義をベースにした研究テーマ・研究問い・インタビューガイドがデフォルトで組み込まれており、現場での記録をそのまま分析に接続できるように設計してあります。
Data is stored locally in each browser. JSON / CSV export available inside each tool. Dev / GitHub Pages
